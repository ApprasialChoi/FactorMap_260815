# FactorMap — 그밖의요인 통계맵

개공비율(사례단가 ÷ 개별공시지가)과 **토지단가**를 기초로, 선택된 평가사례·거래사례의
그밖의 요인 보정치 통계를 지도에서 확인하는 도구.

## 데이터
- 평가사례 6,252건 (해남·영암·무안) — `p` = 사례 토지단가
- 거래사례 880건 (지목 '토지' 나지 · 단가 기재분) — `p` = 토지 거래단가
- **거래사례(배분) 154건** — 복합거래(토지+건물)를 배분법으로 처리한 뒤의 토지단가
  - `p` = (거래금액 − 건물가격) ÷ 토지 거래면적
  - 건물가격 = 건물 공부면적 × 표준단가 × 잔가율(정액법, 급수4 기준)
  - 출처: `거래사례_배분법_20260815_201934.xlsx` 의 「배분법」 시트
  - 판정 O 사용가능 138 / △ 검토필요 16 수록,
    X 토지단가 음수 42 · 사용승인일 역전 7 · 계산불가 67 · 용도지역·지목 미상 2 는 제외

## 기능
- **지표 전환** — 개공비율 ↔ 토지단가(원/㎡). 대푯값·통계표·히스토그램·지도 pill·리 목록이 함께 바뀜
- 필터: 사례유형 / 지역(시군구→읍면→리) / 용도지역 12종 / 이용상황 5그룹(지목 기준) / 기간 / 배분품질(O·△)
- 통계: 원자료 · IQR 1.5× 정제 · 상하위 10% 절사 비교, 히스토그램(정제 경계 표시), 리별 정제 중위값
- **엑셀 내려받기** — 화면 조건 그대로 `.xlsx`(4시트: 사례목록·통계·리별·추출조건) 또는 CSV(UTF-8 BOM)
- **지적편집도(용도지역)** — 카카오맵 `USE_DISTRICT` 오버레이 토글. 위성(HYBRID) 토글도 함께 제공
  - 카카오 SDK 도메인 제한 때문에 **GitHub Pages 주소에서만 동작** (로컬 파일·localhost 에서는 안내 알림)

## 본건 균형검토 (패널 상단 탭)
`★★솔라시도_v9.xlsx` 「별첨1. 공시지가(일련수정)」의 본건 3,229행(2,261필지)을 필지 폴리곤으로 보며
결정단가·개별요인·기타요인의 균형을 검토하는 모드. 사례 마커·리 경계는 숨겨진다.
- 필터: 블록 / 리 / 용도지역 / 이용상황(지목 그룹) / 지목 / 개별요인 6항목(값 선택)·누계(범위) / 기타요인 /
  결정단가 범위 / 평가액 범위 / 결정단가 미기재 행 포함 여부
- 지도: 조건 통과 필지의 폴리곤을 결정단가 5분위 색으로 표시(범례 우하단), 레벨 3 이하에서 단가 라벨.
  필지 색은 통과 행 중 사정면적이 가장 큰 행 기준. 폴리곤·라벨 클릭 → 행별 개요(공시지가·시점·지역·개별·기타·산정·결정·평가액)
- 요약표: 용도지역 × 이용상황 **평균 결정단가**, **기타요인**(평균 + 값 종류). 용도지역·이용상황 필터를 뺀 조건으로
  집계하며, 칸 클릭 → 그 조합만 지도 표시
- 엑셀 내려받기: 통과 행 목록 + 요약표 2개 + 조건
- 데이터: `tools/build_balance.py` → `data/balance.js`. 폴리곤은 `드론관련/Qfield_day1/사업지구_연속지적도.shp`
  (EPSG:5186 → WGS84, 0.3 m 단순화) · 2,253/2,261 필지 매칭, 미매칭 8필지는 목록에 '폴리곤 없음' 표시
- 시트의 X3 합계는 `SUBTOTAL(109)` 라 시트 필터 상태에 따라 달라짐(전체 합 951,870,445,400) — 수록하지 않음

## 주의
- 지표를 토지단가로 두면 단가 미기재분은 통계에서 빠짐 — 제외 건수를 패널 하단에 표시함
- 배분 결과는 표준단가·내용연수 가정에 좌우됨. `! 건물 재조달원가·내용연수 기준 정리 필요 !`

## 데이터 갱신
1. `build_factormap.py` — 평가사례 + 거래사례(나지) → records.js
2. `fm_add_alloc.py` — 배분법 시트의 거래사례(배분) 154건을 t=2 로 덧붙임
3. `build_balance.py` — 별첨1(본건) + 연속지적도 → balance.js (index.html 의 `?v=` 도 함께 갱신)
