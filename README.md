# FactorMap — 그밖의요인 통계맵

개공비율(사례단가 ÷ 개별공시지가)을 기초로, 선택된 평가사례·거래사례의
그밖의 요인 보정치 통계를 지도에서 확인하는 도구.

- 데이터: 해남·영암·무안 평가사례 6,252건 + 거래사례(토지·단가 기재분) 880건
- 필터: 사례유형 / 지역(시군구→읍면→리) / 용도지역 12종 / 이용상황 5그룹(지목 기준) / 기간
- 통계: 원자료 · IQR 1.5× 정제 · 상하위 10% 절사 비교, 히스토그램(정제 경계 표시), 리별 정제 중위값
- 데이터 갱신: scratchpad의 build_factormap.py 재실행 → data/records.js 교체

지목 그룹: 공장(공장용지·창고용지) / 대 / 잡종지(잡종지·주차장) / 전답(과수원·답·전·목장용지) / 임야
