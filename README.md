# FactorMap — 그밖의요인 통계맵

개공비율(사례단가 ÷ 개별공시지가)과 **토지단가**를 기초로, 선택된 평가사례·거래사례의
그밖의 요인 보정치 통계를 지도에서 확인하는 도구.

## 데이터
- 평가사례 6,252건 (해남·영암·무안) — `p` = 사례 토지단가
- 거래사례 880건 (지목 '토지' 나지 · 단가 기재분) — `p` = 토지 거래단가
- **거래사례(배분) 154건** — 복합거래(토지+건물)를 배분법으로 처리한 뒤의 토지단가
  - `p` = (거래금액 − 건물가격) ÷ 토지 거래면적
  - 건물가격 = 건물 공부면적 × 표준단가 × 잔가율(정액법, 급수4 기준)
  - 출처: `거래사례_배분법_20260815_201934.xlsx` 의 「배분법」 시트
  - 판정 O 사용가능 138 / △ 검토필요 16 수록,
    X 토지단가 음수 42 · 사용승인일 역전 7 · 계산불가 67 · 용도지역·지목 미상 2 는 제외

## 기능
- **지표 전환** — 개공비율 ↔ 토지단가(원/㎡). 대푯값·통계표·히스토그램·지도 pill·리 목록이 함께 바뀜
- 필터: 사례유형 / 지역(시군구→읍면→리) / 용도지역 12종 / 이용상황 5그룹(지목 기준) / 기간 / 배분품질(O·△)
- 통계: 원자료 · IQR 1.5× 정제 · 상하위 10% 절사 비교, 히스토그램(정제 경계 표시), 리별 정제 중위값
- **엑셀 내려받기** — 화면 조건 그대로 `.xlsx`(4시트: 사례목록·통계·리별·추출조건) 또는 CSV(UTF-8 BOM)
- **지적편집도(용도지역)** — 카카오맵 `USE_DISTRICT` 오버레이 토글. 위성(HYBRID) 토글도 함께 제공
  - 카카오 SDK 도메인 제한 때문에 **GitHub Pages 주소에서만 동작** (로컬 파일·localhost 에서는 안내 알림)

## 주의
- 지표를 토지단가로 두면 단가 미기재분은 통계에서 빠짐 — 제외 건수를 패널 하단에 표시함
- 배분 결과는 표준단가·내용연수 가정에 좌우됨. `! 건물 재조달원가·내용연수 기준 정리 필요 !`
